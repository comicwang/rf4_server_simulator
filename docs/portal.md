# 个人中心

gateway 的 `/portal/` 提供角色资料、余额和游戏金币会员购买。管理员在玩家档案中设置个人中心账号和密码；每个账号唯一绑定一个角色，同一网络下的不同玩家也会读取各自角色信息。个人中心会话在退出、密码重置或封禁时失效。

RF4 客户端会发送密码的 SHA-1 摘要，网页发送原密码；两种输入使用各自的 bcrypt 校验值并绑定同一账号版本。更新前已创建的账号需在更新后重新登录一次网页个人中心，以补齐游戏校验值；新建或重置账号时自动同步生成。密码和客户端摘要均不以明文保存或写入日志。

> **身份边界：** `/login.php` 与网页个人中心都校验管理员为玩家设置的账号凭证，并读取该账号绑定的角色。未配置本地 Steam ticket 验证，匿名 Steam 登录会被拒绝。个人中心只接受 HTTPS；不要把旧版明文兼容端口暴露到可信本机/局域网之外。

会员仅使用本地游戏金币，普通、限时与永久会员状态共用主线存储方法；购买失败可重试同一订单，避免重复扣款。页面静态资源随服务提供，无需第三方图片服务。
